Welcome to **AI Prototyping for UX Designers** — your practical guide to building interactive, high-fidelity prototypes without needing deep coding expertise. This guide shows you how to harness AI coding assistants like [GitHub Copilot](https://github.com/features/copilot), [Claude](https://claude.ai), or [Cursor](https://www.cursor.com/) alongside a GitHub repository to turn your design concepts into working, testable interfaces — in hours, not days. Whether you're a seasoned UX professional or just getting started, you'll learn a repeatable workflow that keeps you in the driver's seat.

---

## What You'll Learn

By the end of this guide, you'll know how to:

- ✅ Translate design ideas and intent into clear, effective AI prompts
- ✅ Generate UI components and layouts directly from your descriptions
- ✅ Iterate on prototypes quickly using AI feedback loops
- ✅ Manage your prototype versions and prompt history with GitHub

<Tip>
  Never used GitHub before? No problem — start with the **Quickstart** in [Set Up Your Environment](/getting-started/setup). It walks you through every step from scratch, no prior experience needed.
</Tip>

## Your Learning Journey

Follow these four stages to go from zero to a working AI prototyping workflow:

<Steps>
  <Step title="Set Up Your Environment">
    Install the tools you need, create your GitHub repository, and configure your AI assistant. This foundation makes every step after it faster and more reliable.
  </Step>
  <Step title="Learn the Core Workflow">
    Master the **Describe → Generate → Refine** loop — the repeatable process at the heart of AI prototyping. You'll learn how to write prompts that get great results on the first try.
  </Step>
  <Step title="Apply Practical Techniques">
    Go deeper with techniques for generating specific UI components, handling design system constraints, and iterating with stakeholder feedback — all without writing code by hand.
  </Step>
  <Step title="Explore Examples">
    Walk through real prototype builds — from a simple onboarding flow to a full analytics dashboard — and adapt them to your own projects.
  </Step>
</Steps>
